# Start here

Book of Life is a reference library, not a course or a set of approved
instructions. Before using an entry, read the
[disclaimer](DISCLAIMER.md). No entry is a complete or sole source.

## A first visit

1. Choose a language and browse a domain, or search for a subject.
2. Read the entry's safety level and verification status before its body.
   `draft` means unchecked; `green` is not a guarantee of safety.
3. Follow the source links and check primary sources, current local rules,
   and qualified professionals before relying on any information.
4. If you find an error, a missing hazard, or a procedure that did not work,
   report it through the contribution channels. Read
   [Field testing](FIELD-TESTS.md) before publishing a test report.

## Use an app offline

The [web reader](../apps/web-ts/README.md) can be built as a static bundle and
opened without a server. Other readers and device apps are listed in
[Applications](APPS.md). Keep a local copy of the entries and their sources;
the reader's offline availability does not make the material verified or
current.
