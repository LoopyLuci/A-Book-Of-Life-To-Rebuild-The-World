# Interactive Simulators

Offline-capable, single-file HTML simulators for systems that are easier to
understand by manipulation than by reading.

Each simulator:

- Is a single `.html` file with inline CSS/JS.
- Runs entirely offline (no CDN dependencies).
- Encodes the canonical parameters from its linked entry.
- Emits a JSON snapshot for embedding in lessons.
