# 船体設計の原則
> **Domain:** ship | **Difficulty:** apprentice | **Safety:** green

*本資料は参考情報にすぎません。実行に移す前に、一次資料および有資格の専門家に照らして必ず確認してください。本項目を唯一の情報源として用いてはなりません。*

## 概要

船体とは、積まねばならない容積、水中で生じる抵抗、荒れた海での挙動という三者の折り合いである。基本となる原則は、設計は長さからではなく重量から始まるという点である。排水量は船の重量そのものであり、その重量を動かすのにどれだけの代価を要するかは、水線下の船体形状が決める。肥大度と船幅は、復原性と貨物容積をもたらす一方で、その代償として抵抗を増やす。したがって、あらゆる選択はトレードオフであり、それを勘定に入れなければならない。

## 前提条件

- アルキメデスの原理と排水量の意味
- 形状係数とオフセットのための基礎的な三角法
- 縮尺図面の読み方、およびディバイダーとスプライン（フェアリング用の弾性定規）の使い方
- 海事用語：喫水、乾舷、船幅、トリム

## 材料と工具

- 縮尺図面用紙、製図板、ディバイダー、スプライン
- プラニメーター、または図面上の面積を測るための方眼法
- 海水1025 kg/m3および淡水1000 kg/m3に対する静水力学データ
- 方形係数、柱形係数、水線面積係数の参照表
- 抵抗データ、およびプロペラ回転数の推定器
- 重量・モーメント表、および喫水標の型板

## 手順

### 要件を定める

1. 積載貨物、乗組員、燃料、予備を一覧にする。これらの合計が載貨重量である。
2. 構造、機関、艤装の軽荷重量を加え、その合計を水の密度で割って、船体が水線下で排除すべき容積を求める。
3. 貨物から全長と排水量を選び、汎用船では長さと幅の比を4:1から6:1の間に保つ。

### 船型を選ぶ

1. 方形係数を、排水容積をL x B x Tで割った値として計算する。ただしTは喫水である。排水量型船体では0.4から0.6を目標とする。
2. 柱形係数は0.55から0.75、水線面積係数は0.6から0.8を目指す。より肥えた船型は、約0.8までなら、より多く積めるが抵抗も増えることを忘れてはならない。
3. トレードオフを秤にかける。幅を広げ肥大度を増すと、初期復原モーメントと貨物容積は増すが、抵抗が増し、波浪中の動揺も大きくなる。

### 線図を描く

1. バトックライン、すなわち横断面を、船体長さあたりおよそ4つのステーションで描く。水線は、設計喫水、満載喫水、およびそれらより上の2本について描く。
2. 基線、キール、船首材と船尾材、甲板縁、シア（舷弧）を定める。端部には10-90-10則を用い、垂線より前方と後方にそれぞれ長さの10%、その間に90%を割り当てる。
3. スプラインで断面をフェアリングし、各線の曲率が連続していること、および断面同士が互いに滑らかに整合していることを確かめる。

### 馬力を推定する

1. 摩擦抵抗を 0.5 x rho x V^2 x S x C_f として推定する。レイノルズ数が1e7を超える平滑な船体では、C_fは0.075を(log10(L) - 2)の2乗で割った値とする。
2. 剰余抵抗を加える。中程度の速力の排水量型船体では、全抵抗の15%から40%を見込む。
3. 軸馬力を、抵抗に速力を掛け、総合効率で割って推定する。プロペラ付きの小型ディーゼルでは総合効率は0.35から0.50であり、これをプロペラの毎分回転数に換算する。

## 安全上の注意

- これは机上の作業であるが、そこから得られる数値が浮力を左右する。復原性と乾舷は、軽荷状態ではなく、貨物を積んだ状態で確認すること。
- 浮かんでいる船体の上で単独作業をしてはならない。梯子と安全ハーネスを使い、救命胴衣を手の届くところに置くこと。
- 船上での真の危険は冷水と溺水であり、閉鎖された空間での転覆は瞬く間に事態を致命的にする。
- 追い波の中でも甲板縁が濡れないよう、乾舷を十分に高く保つこと。
- 乗組員や貯蔵品の変更を含め、重量が変わるたびに復原性を再確認すること。
- 余裕なしに排水量や喫水を承認してはならない。海水の密度は温度と塩分によって変化する。
