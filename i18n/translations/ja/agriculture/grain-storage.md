# 穀物の貯蔵と害虫防除
> **Domain:** agriculture | **Difficulty:** apprentice | **Safety:** yellow

*本資料は参考情報にすぎません。実行に移す前に、一次資料および有資格の専門家に照らして必ず確認してください。本項目を唯一の情報源として用いてはなりません。*

## 概要

湿った状態や温かい状態で貯蔵した穀物は、カビ、昆虫、げっ歯類（ネズミ類）により、数週間で一季分の労働の成果を失うおそれがある。決定的な変数は水分と温度の二つである。水分を約12-14%未満まで乾燥させた穀物を、冷涼に保ち密閉すれば、6-24か月間貯蔵できる。容積1 m³の貯蔵容器には、おおよそ600-800 kgの穀物が入る。

## 前提条件

- 穀物の栽培と収穫
- 乾燥した、地面より高くした貯蔵場所

## 材料と工具

- 高床式で密閉できる貯蔵容器、または気密貯蔵袋（ハーメチックバッグ）
- 水分計
- 清潔なターポリンとパレット
- 珪藻土
- ネズミ侵入防止用メッシュ
- ラベルと記録帳

## 手順

### 1. 収穫と乾燥

1. 成熟期に収穫し、湿った穀物やカビの生えた穀物を良質な穀物に混ぜないようにする。
2. 水分12-14%まで乾燥させる。確認は噛んで行うのではなく、水分計で行う。
3. 清潔なターポリンの上に薄く広げ、通風と日光のもとで乾燥させる。
4. 貯蔵前に穀物を冷ます。温かい穀物は、冷える際に結露（汗をかく現象）を起こす。

### 2. 貯蔵施設の清掃と準備

1. 唐箕（とうみ）や篩（ふるい）で、籾殻（もみがら）、砕けた粒、粉塵を取り除く。
2. 貯蔵容器を清掃し、古い穀物を取り除き、穴や隙間を補修する。
3. 貯蔵容器を床から持ち上げ、壁から離して設置する。
4. 通気口にネズミ侵入防止用メッシュを取り付け、蓋は密閉しておく。

### 3. 充填と保護

1. 貯蔵容器は一度の作業で満たし、表面を平らにならす。
2. 少量の場合は気密貯蔵袋（ハーメチックバッグ）を使い、完全に密封する。
3. 使用が認められている場合は、害虫防除のため、ラベル記載の使用量で珪藻土を混ぜる。
4. 各ロットに、収穫日と水分測定値を記したラベルを付ける。

### 4. 監視と処置

1. 毎月、発熱、結露、昆虫、ネズミの糞がないか点検する。
2. 中央部と底部にプローブを差し込んで確認する。熱を持った箇所（ホットスポット）はカビまたは昆虫の発生を意味する。
3. 被害を受けた穀物は取り出して先に使い、清潔な穀物と混ぜない。
4. 燻蒸（くんじょう）は、訓練を受けた者の支援のもと、承認された製品でのみ行う。居住空間では決して行わない。

## 安全上の注意

- **黄色の危険：** カビの生えた穀物にはアフラトキシンが含まれることがあり、肝障害や発がんの原因となる。目に見えてカビの生えた穀物を食べたり、家畜に与えたりしてはならない。
- 穀物の粉塵は爆発することがある。換気を行い、裸火を避け、清掃時にはマスクを着用する。
- 燻蒸剤は毒性が非常に高い。訓練を受け、呼吸用保護具を着用し、警告標識を掲示したうえでのみ使用する。
- ブリッジ（穀物が固まって空洞ができた状態）を起こしている可能性のある貯蔵容器には、決して立ち入らない。穀物に飲み込まれると、数秒で命に関わる。
