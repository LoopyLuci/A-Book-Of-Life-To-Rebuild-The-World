# コミュニティの食料安全保障計画
> **Domain:** society | **Difficulty:** apprentice | **Safety:** green

*本資料は参考情報にすぎません。実行に移す前に、一次資料および有資格の専門家に照らして必ず確認してください。本項目を唯一の情報源として用いてはなりません。*

## 概要

食料安全保障とは、コミュニティがどれだけ生産するかだけの問題ではありません。すべての世帯が、一年を通じて十分な量の安全で栄養のある食料を入手できるかどうかの問題です。計画では、生産、貯蔵、不足、そして脆弱な世帯を地図化し、危機が起こる前に備蓄と配給の規則を定めます。貯蔵が可能な場合は、主食の備蓄を少なくとも3か月分とすることを目標にします。

## 前提条件

- コミュニティ・オーガナイジング
- 基本的な記録管理

## 材料と工具

- 世帯食料調査票
- 地図と記録類
- 秤と電卓
- 貯蔵在庫記録用紙
- 種子の備蓄
- 配給名簿と掲示板

## 手順

### 1. 状況を評価する

1. 各世帯を対象に、貯蔵量、収入、菜園の規模、食事上の必要性を調査する。
2. 地域の生産、野生の食料、市場、貯蔵施設を地図化する。
3. 脆弱な層を特定する。子ども、妊婦、高齢者、障害のある人、土地を持たない世帯などである。
4. 端境期（食料の乏しい季節）と不足量の規模を見積もる。

### 2. 備蓄と優先順位を定める

1. 目標とする備蓄量を合意する。例えば、1世帯あたり主食3か月分とする。
2. 単一の作物ではなく、多様で貯蔵できる食料を優先する。
3. 備蓄が必要になる前に、受給資格と配給の規則を明確に定めておく。
4. 種子の備蓄は、食用の備蓄とは別に保護する。

### 3. 整備と貯蔵

1. 乾燥し、涼しく、害虫を防げる世帯用および共同の貯蔵を支援する。
2. 菜園、小家畜の飼育、食品の保存加工を推進する。
3. 道具、脱穀、貯蔵を共同で運用して費用を抑える。
4. 在庫の出し入れをすべて記録し、毎月、腐敗がないか点検する。

### 4. 配給と見直し

1. 信頼できる地域の機関を通じて、公開の記録を付けながら配給する。
2. 最も脆弱な人々を最優先とし、声の大きい人に与えることは避ける。
3. 作付け前と冬の前に計画を見直す。
4. 不作、価格の変動、新たな転入者に応じて調整する。

## 安全上の注意

- **緑の危険：** 主なリスクは物理的なものではなく社会的なものです。食料があっても、不平等な配分や腐敗によって栄養不良が生じることがあります。
- カビの生えた食料や期限切れの食料は、急性中毒を起こすおそれがあるため、決して配給してはなりません。
- 配給は平穏かつ透明に行い、規則と配給量を公表してください。
- 脆弱な世帯を特定する際は、尊厳とプライバシーを尊重してください。
