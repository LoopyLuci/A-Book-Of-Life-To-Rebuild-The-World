# 交流回路解析とインピーダンス
> **Domain:** computers | **Difficulty:** apprentice | **Safety:** green

*本資料は参考情報にすぎません。実行に移す前に、一次資料および有資格の専門家に照らして必ず確認してください。本項目を唯一の情報源として用いてはなりません。*

## 概要

交流では、電圧と電流が同時に増減しなくなるため、電圧を電流で割っただけの単純な比は有用な値ではなくなります。基本となる考え方は、各素子をそのインピーダンス（抵抗分とリアクタンス分からなる複素数）に置き換え、直流とまったく同じ回路方程式を解くことです。リアクタンスは周波数によって決まるため、定常状態である挙動を示す回路が、50 Hz では全く別の挙動を示すことがあります。

## 前提条件

- キルヒホッフの法則および直列・並列の規則のための「直流回路解析」
- 直交形式と極形式による複素数
- 正弦関数・余弦関数、位相、位相差
- リアクタンス素子のための基礎的な微分・積分
- 実効値(RMS)、ピーク値、ピーク・ツー・ピーク値の関係

## 材料と工具

- ファンクションジェネレータとオシロスコープ
- 実験用電源と、静電容量レンジ付きのデジタルマルチメータ
- E12系列およびE24系列の抵抗、コンデンサ、インダクタ
- 共振・フィルタ実験用のデカードボックス、または一組の値の部品
- 試験用インダクタを作るための銅線とボビン
- 商用電源に接続する作業のための絶縁トランス

## 手順

### 回路をフェーザに変換する

1. 各抵抗をRに、各コンデンサおよびインダクタをそのリアクタンスに置き換えます。X_L = 2 x pi x f x L、X_C = 1 / (2 x pi x f x C)。
2. 各素子のインピーダンスを直交形式で書きます。Z_R = R、Z_L = j X_L、Z_C = -j X_C。
3. 直流と同じ規則で、直列のインピーダンスを加算し、並列の枝を合成します。その際、j の項は別々に扱います。その後、結果を極形式に変換します。大きさは R^2 + X^2 の平方根、角度は X / R の逆正接（アークタンジェント）です。

### 交流回路網を解く

1. インピーダンス回路網にキルヒホッフの法則を適用し、フェーザ電流とフェーザ電圧を求めます。
2. フェーザの解を時間領域に戻します。その際、正弦波の実効値(RMS)はピーク値を 1.414 で割ったものであることに注意します。
3. 電力で結果を検算します。有効電力は P = V x I x cos(phi)、無効電力は Q = V x I x sin(phi)、皮相電力は S = V x I（単位はボルトアンペア）です。

### 共振を求める

1. リアクタンスを等しいとおき、共振周波数 f0 = 1 / (2 x pi x sqrt(L x C)) を求めます。
2. 半値電力周波数を測定し、Q値（尖鋭度）Q = f0 / (f2 - f1) を計算します。さらに、sqrt(L / C) を直列抵抗で割った式と照合します。
3. 共振時には回路電流が最大となり、コンデンサの両端電圧は電源電圧のQ倍になり得ることに留意します。

### フィルタを設計する

1. 仕様から遮断周波数を決め、単純なRC型ローパスフィルタの抵抗 R = 1 / (2 x pi x f x C) を計算して、製作します。
2. 遮断周波数の 0.1 倍、1 倍、10 倍で応答を測定し、出力が 1 デカードあたり 20 dB 低下していることを確認します。
3. 遮断周波数での位相のずれを確認します。1次フィルタでは 45 度です。減衰が十分に急峻でなければ、2段目を追加します。

## 安全上の注意

- 商用電源の電圧は人を死に至らしめます。電源に接続された回路はすべて致命的であるとみなし、適切な訓練、監督、装備のもとでのみ、絶縁トランスを使用して作業してください。
- 心臓を止める電流はわずかです。約 0.5 mA が感知閾値、10 mA が離脱限界(let-go)閾値、30 mA で呼吸が止まることがあり、50 mA で心室細動を起こすことがあります。
- 充電されたコンデンサは、電源を切った後もエネルギーを保持します。メータのインピーダンスは放電させるには高すぎるためです。放電抵抗を使用し、ノードに触れる前にメータで電圧がないことを確認してください。
- 共振回路ではコンデンサの両端に高電圧が生じることがあります。また、フライバックコンバータや昇圧コンバータは、低電圧に見えるノードに数百ボルトを発生させることがあります。
- ファンクションジェネレータの出力と実験用電源の出力は互いに絶縁しておき、信号源を電源出力に並列に接続してはいけません。
- コンデンサの耐電圧とリップル電流の定格を確認し、共振回路ではコンデンサの両端電圧が電源電圧よりはるかに高くなり得ることを忘れないでください。
