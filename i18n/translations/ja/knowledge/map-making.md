# 地図作成
> **Domain:** knowledge | **Difficulty:** apprentice | **Safety:** green

*本資料は参考情報にすぎません。実行に移す前に、一次資料および有資格の専門家に照らして必ず確認してください。本項目を唯一の情報源として用いてはなりません。*

## 概要

有用な地図には、旅行者が必要とする情報、すなわち距離、方位、水場、危険箇所、目印が記録されています。測量用の精密機器は必要ありません。コンパス、実測した基線、歩測、そして一貫した記号体系があれば、ルート計画、災害対応、地域の記録に十分な精度のスケッチ地図を作成できます。

## 前提条件

- コンパスの使用技能と歩測（ペースカウント）の技能
- 基本的な算数と縮尺図の作図

## 材料と工具

- 磁気偏角を調整できるコンパス
- 基線用の巻尺またはロープ
- 方眼紙、クリップボード、鉛筆、消しゴム
- チェックポイント用のGPSまたはスマートフォン
- ポール（測量用ポール）または旗
- 斜面測定用のクリノメーターまたはスマートフォンの水準器
- 防水マップケース

## 手順

### 1. 縮尺と方位を設定する

1. 対象範囲と図示する最小の地物を決め、縮尺を選びます。たとえば、村なら 1:2,000、地区なら 1:50,000 などとします。
2. 北を示す矢印を描き、磁気偏角を書き留めます。
3. 地上に既知の基線を設定し、2回測定します。
4. 動かない固定の基準点を2点設けます。

### 2. 方位と距離による測量

1. 各基準点から、角、建物、井戸、道路の交差点に対する方位を測ります。
2. 各距離を実測または歩測します。まず100 mで自分の歩幅を較正してください。
3. 各点について、その方位に沿って線を引き、縮尺に換算した距離を記して作図します。
4. 到達できない地物は、既知の2点からの三角測量で位置を求めます。

### 3. 地形と記号を加える

1. 傾斜の変換点と標高点から等高線をスケッチします。GPSの軌跡を利用してもかまいません。
2. 水場、季節河川、洪水痕跡線、橋、急勾配の箇所を記入します。
3. 建物、田畑、道路、危険箇所に一貫した記号を用いた凡例を付けます。
4. 表題、日付、スケールバー、北矢印、測量者名を加えます。

### 4. 確認と複製

1. 地元の案内人とともに地図を持って歩き、現地で誤りを修正します。
2. 複数のチェックポイントで距離と方位を比較します。
3. 完成した地図をインクで清書するか、スキャンして複製します。原図は現場用の写しとは別の場所に保管します。
4. 磁気偏角は緩やかに変化するため、その値と日付を記録します。

## 安全上の注意

- **緑の危険：** 現地での地図作成はリスクが低い作業ですが、交通、天候、無断立入りは現実的な懸念事項です。許可を得て、立入制限区域は避けてください。
- スマートフォンのバッテリーだけに頼らず、コンパスと紙の地図を携行してください。
- 河川の横断や急斜面では、同行者を確保し、引き返す時刻を決めておく必要があります。
- スケッチ地図は、法的な土地測量ではありません。
