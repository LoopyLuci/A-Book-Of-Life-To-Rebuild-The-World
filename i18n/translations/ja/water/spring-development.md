# 湧水の開発と保護
> **Domain:** water | **Difficulty:** journeyman | **Safety:** yellow

*本資料は参考情報にすぎません。実行に移す前に、一次資料および有資格の専門家に照らして必ず確認してください。本項目を唯一の情報源として用いてはなりません。*

## 概要

湧水（泉）とは、地下水が地表に現れる場所のことです。開発とは、その流れを泥の中に溜まるに任せず、清浄な状態で取水することを指します。保護された湧水槽（スプリングボックス）、密閉した集水管、集水域を囲うフェンスを整えることで、にじみ出る水を、重力式送水管を長年にわたって支える水源に変えることができます。

## 前提条件

- 流量を測定するための乾季の現地踏査
- 土地および水利用の許可
- 石積み・コンクリート工事と配管敷設の技能

## 材料と工具

- 湧水槽用の石またはコンクリート
- 礫と砂のろ過充填材
- 集水管および越流管
- 止水用の粘土またはモルタル
- 蓋用スラブとフェンス支柱
- 下流側の水槽（水飲み場用）または減圧水槽（ブレークプレッシャータンク）

## 手順

### 1. 湧水の調査

1. 下流側のしみ出しではなく、真の水源（湧出点）を特定する。
2. 乾季に、容器とストップウォッチで流量を測定する。
3. 上手側に試掘坑を掘り、帯水層（含水層）を見つける。
4. 上流側の土地利用について、便所、家畜、化学物質の保管がないか確認する。

### 2. 掘削と湧水槽の構築

1. 湧出点の下方に安定した掘削穴を開け、崩れやすい地盤は土留めで支える。
2. 底が開いた水密構造の槽を築き、帯水層内に据える。
3. 集水部の周囲に清浄な礫を充填し、槽の壁を地表水に対して止水する。
4. 床を集水管に向けてわずかに傾斜させる。

### 3. 流出口の設置

1. 底近くにスクリーン付きの集水管を取り付ける。
2. 構造物を洗掘せずに余剰水を排出できるよう、より太い越流管を取り付ける。
3. 水を蓋付きの水槽またはスタンドパイプへ送る。管路は埋設し、空気が溜まる低所を作らないこと。
4. 蓋用スラブを密閉し、点検口を取り付ける。

### 4. 集水域の保護

1. 湧水の周囲、特に上手側を少なくとも 10-30 m 囲うフェンスを設ける。
2. 動物と便所を直近の集水域に入れない。
3. 斜面を安定させるため、根の深い植物を植える。
4. 暴風雨のあとに点検し、浸食が湧水槽に達する前に補修する。

## 安全上の注意

- **黄色の危険：** 掘削部は崩壊するおそれがあります。深い掘削穴では決して単独で作業せず、入る前に壁面を土留めで支えてください。
- 湧水は自動的に安全であるとは限りません。飲用に使う場合は水質検査を行い、消毒してください。
- 下流の利用者に水を供給している湧水を、合意なしにせき止めたり付け替えたりしてはなりません。水利権と生計がかかっています。
- 溺水と汚染を防ぐため、湧水槽には蓋をしてください。
