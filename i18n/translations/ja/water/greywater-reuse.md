# 中水（グレイウォーター）の再利用
> **Domain:** water | **Difficulty:** apprentice | **Safety:** yellow

*本資料は参考情報にすぎません。実行に移す前に、一次資料および有資格の専門家に照らして必ず確認してください。本項目を唯一の情報源として用いてはなりません。*

## 概要

グレイウォーター（雑排水）とは、浴槽、シャワー、手洗い、洗濯から出る水のことです。家庭排水の50-80%を占めることがあり、樹木、低木、一部の作物を灌漑するのに十分な養分をなお含んでいます。安全な方法は、トイレの汚水と分離し、使用する薬剤を制限し、貯留せずに土壌表面より下へ散水することです。

## 前提条件

- グレイウォーター専用の排水管
- この水を利用できる庭または造園区画
- 再利用および離隔距離に関する地域の規則

## 材料と工具

- 切替弁（ダイバーターバルブ）とグレイウォーター対応の配管
- マルチ盆（マルチベイスン）または地下灌漑ライン
- 砂利とフィルタースクリーン
- シャベルと水準器
- 手袋と保護眼鏡
- 低塩分でホウ砂を含まない石けん

## 手順

### 1. システムの計画

1. 地域の衛生規則を確認し、井戸、小川、基礎からの離隔距離を保ちます。
2. 流量を見積もります。使用量の少ない世帯でおよそ100-150 L/日の排水が出ます。
3. 流量を植栽面積に合わせ、土壌を過飽和にしないでください。
4. 必要なときにグレイウォーターを下水道または浄化槽へ流せるよう、切替弁を備えた単純な自然流下式を選びます。

### 2. 分離とプレフィルター

1. 浴槽、シャワー、洗面台、洗濯の排水を切替弁へ導きます。
2. トイレの汚水、台所の油脂、食器洗い機の排水はシステムに入れないでください。
3. 髪の毛や糸くずを捕らえる粗目のスクリーンを取り付け、毎週清掃します。
4. 塩素系漂白剤、ホウ砂、土壌生物に害を与える強力な消毒剤は避けます。

### 3. 地表面より下への散水

1. 樹木や低木の周囲のマルチ盆、または地下点滴ラインへ配管します。
2. 接触、臭気、蚊を抑えるため、吐出口をマルチで覆います。
3. 土壌が回復できるよう、散水箇所を交互に切り替えます。
4. 根菜類、葉物野菜、生で食べるものには灌漑しないでください。

### 4. 監視と保守

1. 水たまり、臭気、ボウフラがないか確認し、詰まりはただちに直します。
2. 特に乾燥地の土壌では塩類集積に注意し、清水で洗い流して（リーチング）ください。
3. 使用した石けんや洗浄剤の記録を残します。
4. 世帯員の誰かが感染性の胃腸疾患にかかった場合は、再利用を中止してシステムを修理します。

## 安全上の注意

- **黄色の危険：** グレイウォーターには病原体が含まれています。24時間を超えて貯留してはならず、絶対に飲んではいけません。
- 地下に散水し、子どもやペットを吐出口に近づけないでください。
- 可食の根菜類や、生で食べる葉にグレイウォーターを使ってはいけません。
- 井戸、湧水、地表水の汚染を避け、離隔距離を維持してください。
