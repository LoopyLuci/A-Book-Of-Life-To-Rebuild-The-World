# 寒冷曝露と低体温症
> **Domain:** survival | **Difficulty:** novice | **Safety:** red

*本資料は参考情報にすぎません。実行に移す前に、一次資料および有資格の専門家に照らして必ず確認してください。本項目を唯一の情報源として用いてはなりません。*

## 概要

寒さは体の深部体温を下げることで命を奪います。濡れた衣服、風、疲労は、冷たい空気だけの場合よりはるかに速く熱を奪います。低体温症は、震えと手の不器用さから始まり、錯乱と呂律の乱れへと進み、心停止に至ることがあります。優先すべきは熱の喪失を止めて体幹（深部）を温めることであり、四肢の末端から先に温めてはいけません。

## 前提条件

- 緊急用シェルター
- 火またはその他の熱源

## 材料と工具

- 乾いた断熱用の重ね着と、防風性のある外層
- 暖かい毛布または寝袋
- 着火用具一式
- 意識が完全にはっきりしている場合に与える、温かく甘い飲み物
- 緊急用シェルターまたは風除け

## 手順

### 1. 状態を見極める

1. 抑えられない震え、感覚の麻痺、動作のぎこちなさ、錯乱、眠気がないか確認します。
2. 反応と呼吸を確認します。心停止であれば心肺蘇生(CPR)を行い、助けを呼びます。
3. 本人をそっと扱います。重度の低体温症では、乱暴に動かすと不整脈を誘発することがあります。
4. 寒冷下または風の強い状況で、濡れて疲れ切っている人は、低体温症であるものと見なします。

### 2. 熱の喪失を止める

1. シェルターに移動し、風雨を避けます。
2. 濡れた衣服を脱がせます。必要なら切り取って構いません。本人は水平に寝かせたままにします。
3. マット、リュック、乾いた枝などで地面からの冷えを断ちます。
4. 頭、首、胴体を覆います。可能なら防湿シート（ベーパーバリア）を使います。

### 3. 体幹を温める

1. 胸、首、鼠径部に、肌と肌の接触による熱または温めた毛布をあてます。
2. 温かく甘い飲み物は、本人の意識が完全にはっきりしていて嚥下できる場合にのみ与えます。アルコールは決して与えてはいけません。
3. 火や暖房器具はシェルター内を暖めるために使い、皮膚を直接あぶってはいけません。
4. 重症者は搬送します。現場で強力な再加温を試みてはいけません。

### 4. 凍傷への対処

1. 凍った足に雪をこすりつけたり、マッサージしたり、その足で歩いたりしてはいけません。
2. 再び凍る危険がない場合にのみ再加温します。37-39 C のぬるま湯を使います。
3. 水ぶくれを保護し、手足の指の間は乾いたガーゼで隔てます。
4. 医療機関を受診してください。凍傷は、組織が壊死する前には無害に見えることがあります。

## 安全上の注意

- **赤い危険：** 重度の低体温症は心停止を起こすことがあります。本人をそっと扱い、搬送してください。
- アルコールは熱の喪失を増やし、判断力を損ないます。体を温める目的で決して使わないでください。
- 感覚のない皮膚に直接熱をあててはいけません。やけどがよく起こります。
- 再び凍る可能性のある凍傷の四肢を再加温すると、待つよりも損傷が大きくなります。
