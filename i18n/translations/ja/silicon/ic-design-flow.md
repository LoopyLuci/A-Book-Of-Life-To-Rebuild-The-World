# 集積回路設計フロー
> **Domain:** silicon | **Difficulty:** master | **Safety:** yellow

*本資料は参考情報にすぎません。実行に移す前に、一次資料および有資格の専門家に照らして必ず確認してください。本項目を唯一の情報源として用いてはなりません。*

## 概要

集積回路は、文書化された仕様から、ファウンドリがマスク化できる GDSII レイアウトへと進んでいく。基本原則は、すべての段階が検証ゲートであるということだ。前の段階が実証されるまで、何も先へ進めてはならない。欠陥のコストは段階が進むごとに急激に増大し、再コンパイルで済むものが、チップ全体のリスピンにまで至るからである。したがって設計とは、そのほとんどが証拠をめぐる論証であり、最後に残る成果物は、何を、いつ、どのバージョンのツールで検証したかの記録（アーカイブ）である。

## 前提条件

- デジタル設計とブール論理
- タイミング解析：セットアップ、ホールド、クロックスキュー、クリティカルパス
- Verilog または VHDL、および後述のシミュレータと論理合成ツール
- テクノロジ設計キット：標準セル、LEF および GDEF、GDSII レイヤ、Liberty タイミング
- ブランチ運用とピアレビューを伴うバージョン管理

## 材料と工具

- 仕様書および検証計画書
- RTL ソース、テストベンチ、波形ビューア付きシミュレータ
- 標準セルライブラリと Liberty タイミングファイルを用いる論理合成ツール
- 設計キットを備えた配置配線ツール、およびスタティックタイミング解析ツール
- サインオフツール：リント、CDC、DRC、LVS、ならびに IR ドロップおよびエレクトロマイグレーションの検査
- Git リポジトリ、課題管理ツール、およびウェハコスト、ダイ面積、ウェハあたりのダイ数、一回限りのマスク費用・設計費用を含むコストモデル

## 手順

### 仕様の策定と RTL 記述

1. 仕様を書く：インタフェース、クロック、スループット、レイテンシ予算、消費電力の上限、ダイ面積の上限、コストの上限。
2. RTL より先に検証計画を書く。アサーション、コーナーケース、カバレッジ目標を含めること。
3. 仕様を凍結して記録する。後からの変更が、ずれ（ドリフト）としてではなく変更として表面化するようにするためである。
4. RTL を書き、テストベンチをシミュレーションしてリグレッションに合格させ、ビット幅の不一致、不完全な代入、多重ドライバについてリントを実行する。

### 論理合成と配置

1. 周期と不確かさを含むクロック制約を設定し、目標の面積とタイミングに対して論理合成を実行する。
2. クリティカルパスレポートと消費電力の見積りを読む。動的消費電力はおよそ C x V^2 x f にリーク電力を加えたものである。
3. ツールに任せる前にフロアプランを立てる。メモリ、アナログブロック、I/O リングを配置し、電源グリッドのための余地を残す。
4. 配置を実行し、次にクロックツリー挿入、続いて配線を行い、各段階の後にスキューと配線混雑を確認する。

### サインオフとテープアウト

1. スロー側とファスト側のコーナーで、セットアップとホールドの両方についてスタティックタイミング解析を実行する。
2. スペーシング、密度、アンテナ規則について DRC を、回路図に対して LVS を、さらに IR ドロップおよびエレクトロマイグレーションの検査を実行する。
3. すべての違反を解消したうえで、マルチコーナーのモンテカルロ解析を実行し、まれに起こるタイミング不良を洗い出す。
4. GDSII を出力し、マスクセットを生成し、チェックサムと使用したツールのバージョンとともにアーカイブする。スケジュールのリスクを分散するため、発注を 2 つのファウンドリに分割する。

## 安全上の注意

- ここでの危険はプロジェクト上の危険である。レビューを経ていないテープアウトは、マスクセット全体とその背後にある資金を無駄にする。
- ソースおよびサードパーティの知的財産をロックダウンし、設計ファイルはアクセス制御された保管場所に置くこと。これらには輸出管理規則が適用される。
- 再現可能なビルドを用いる。ツールのバージョン、スクリプト、ライセンスの状態を記録し、アーカイブから正確に再構築できるようにする。
- サードパーティ IP は使用前に検証すること。ハードマクロに潜む微妙なバグは、費用がかさみ、発見も困難である。
- 発注の前に、第二の担当者がサインオフのチェックリストを仕様に照らして確認すること。
- GDSII とマスクセットをアーカイブすること。これらを失えば、マスクの費用を再び支払うことになる。
