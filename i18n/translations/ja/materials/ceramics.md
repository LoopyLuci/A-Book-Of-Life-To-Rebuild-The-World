# 陶芸・窯業（セラミックス）
> **Domain:** materials | **Difficulty:** journeyman | **Safety:** yellow

*本資料は参考情報にすぎません。実行に移す前に、一次資料および有資格の専門家に照らして必ず確認してください。本項目を唯一の情報源として用いてはなりません。*

## 概要

セラミックスは、粘土を容器、タイル、フィルター、そして熱と湿気に耐える耐火部材へと変える技術である。この工程の要点は管理にある。すなわち、均質な粘土、ゆっくりとした乾燥、素地と釉薬に合わせた焼成曲線である。失敗の多くは、湿った、あるいは乾燥むらのある成形品、可溶性塩類、または素地に合わない釉薬に起因する。

## 前提条件

- 粘土の入手先と水
- 窯焼成または野焼き（ピット焼成）の経験
- 粉じんと熱の安全な取り扱い

## 材料と工具

- 粘土素地とテンパー（砂、シャモット、または粉砕した焼成粘土）
- 水と清潔な混練作業面
- 乾燥用の石膏板または木板
- 窯棚板、支柱（ポスト）、ゼーゲルコーン
- 鉛を含まない釉薬原料
- 防じんマスク、保護眼鏡、耐熱手袋
- バケツ、ふるい、秤

## 手順

### 1. 粘土の試験

1. 粘土を採掘または購入し、石や根を取り除く。
2. 小さな試験タイルを作り、乾燥収縮率と焼成収縮率を測定する。
3. 粘土に亀裂が入る場合や可塑性が高すぎる場合はテンパーを加える。十分に混ぜ、数日間寝かせる。
4. 一度に多量を作る前に、試験タイルを目標温度まで焼成する。

### 2. 成形と乾燥

1. 粘土を菊練りして気泡を除き、水分を均一にする。
2. 指でつまむ成形、ひも作り（巻き上げ）、板作り、またはろくろで成形する。接合部は湿らせたままにし、切り込みを入れる。
3. 布またはビニールをかぶせ、直射日光と風を避けて、革硬度（レザーハード）になるまで、さらに完全乾燥（骨乾燥）になるまでゆっくり乾燥させる。
4. まだ冷たく感じる、または水分で重い成形品を焼成してはならない。

### 3. 素焼き

1. 棚板に十分な間隔をあけて積み込み、各成形品を均等に支える。
2. 水蒸気が抜ける段階（水煙り期）はゆっくり焼成し、その後、その粘土に推奨される素焼き温度まで昇温する。
3. 窯をゆっくり冷却する。急冷すると製品が割れることがある。
4. 釉掛けの前に亀裂がないか点検し、粗い縁を研磨する。

### 4. 施釉と本焼き

1. 食品に触れるものには、鉛を含まない釉薬を使用する。
2. 均一に釉薬を掛け、棚板に釉薬が付かないようにし、高台（足部）をきれいに拭き取る。
3. のぞき穴からコーンを確認しながら、釉薬の熟成温度まで焼成する。
4. 日常使用の前に、仕上がった製品の貫入、溶出、熱衝撃を試験する。

## 安全上の注意

- **黄色の危険：** 粘土と釉薬の粉じんには結晶質シリカが含まれる。湿式で混ぜ、呼吸用保護具を着用し、作業場を乾いたまま掃き掃除してはならない。
- 窯は1,000 Cを超える温度に達し、重度のやけどを負うおそれがある。手袋とトングを使用し、十分な冷却期間を設けること。
- 燃料窯は一酸化炭素を発生させる。屋外、または一酸化炭素警報器を備えた換気のよい場所で焼成すること。
- 鉛釉は、とくに子どもにとって重大な中毒の危険がある。鉛を含まない配合を使用し、食品に触れる表面を試験すること。
