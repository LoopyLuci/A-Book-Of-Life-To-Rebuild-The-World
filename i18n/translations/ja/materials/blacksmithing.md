# 鍛冶と鉄工

## 概要

鍛冶は、鍛鉄や鋼を加熱して叩くことで成形する技術です。工具、武器、金物、締結具を製作します。

## 前提条件

## 材料と工具

- 鍛冶炉（粘土製または鋼製）
- 金床（または密度の高い石）
- ハンマー（2–4 kg）
- 火ばさみ
- 焼入れ槽（油または水）
- 木炭

## 手順

### 炉の設置

1. 中央に羽口を設けた粘土の火床を築く。
2. ふいごまたは送風機を接続する。
3. 木炭を満たし、上から点火する。
4. 送風によって温度が1,200–1,400°Cに上がる。

### 基本の鍛造

1. 金属を鮮やかな橙黄色（1,100°C）になるまで加熱する。
2. 取り出し、ただちに叩く。
3. サクラ色（800°C未満）になったら再加熱する。
4. 延ばし、据え込み、曲げ、穴抜きで成形する。

### 延ばし

1. 一部を加熱する。
2. 金床の角または面上で、長さ方向に対して垂直になるように叩く。
3. 四角い断面を保つため、打撃の合間に90°回転させる。

### 据え込み

1. 端部を加熱する。
2. 金床に向かって下向きに叩く。厚みが増し、長さが短くなる。

### 溶接（鍛接）

1. 両方の部材を白っぽい黄色（1,300°C）まで加熱する。
2. フラックスとしてホウ砂を振りかける。
3. 重ね合わせて素早く叩く。部材どうしは融合する。

### 熱処理

1. **焼なまし：** 赤くなるまで加熱し、灰の中でゆっくり冷やす。
2. **焼ならし：** 赤くなるまで加熱し、空冷する。
3. **焼入れ：** 赤くなるまで加熱し、油または水で急冷する。
4. **焼戻し：** 200–300°Cに再加熱して（藁色から紫色）、その後冷やす。

## 安全上の注意

- **赤い危険：** 火傷、目の損傷、聴力障害がよく起こる。
- 革のエプロン、保護メガネ、耳栓を着用すること。
- 鋼種を知らないまま水中で焼入れしないこと — 割れる危険がある。
- 意図していない限り、水を炉から遠ざけること。
- COがこもらないよう換気すること。
