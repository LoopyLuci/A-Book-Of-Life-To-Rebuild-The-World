# 河川の渡船と小型船による渡河
> **Domain:** transport | **Difficulty:** journeyman | **Safety:** red

*本資料は参考情報にすぎません。実行に移す前に、一次資料および有資格の専門家に照らして必ず確認してください。本項目を唯一の情報源として用いてはなりません。*

## 概要

河川の渡河手段は、地域社会を市場、診療所、農地と結びつけることができますが、流れる水は容赦がありません。小型の渡し船やケーブル案内式のいかだは、想定される積載量に合わせて建造され、訓練を受けた者が運航し、洪水時には運航を停止する場合に最も安全です。速度よりも、乾舷、バランス、そして信頼できるケーブルのほうが重要です。

## 前提条件

- 造船またはいかだ製作の技能
- 低水位時と高水位時の河川調査
- アンカー、ケーブル、滑車金具

## 材料と工具

- 密閉された浮力体を備えた船体またはいかだの船体
- スチールケーブルまたは丈夫なロープ
- 滑車、アンカー、シャックル
- ライフジャケットまたは承認された浮具
- 水くみ（ベーラー）と投げ縄（スローライン）
- オール、竿、または船外機
- 乗降ランプと滑り止め付きデッキ

## 手順

### 1. 渡河地点の調査

1. 低水位時と高水位時の川幅、水深、流速を測定する。
2. 上流の危険箇所（ダム、流木などの障害物、急流、突然の放水）を確認する。
3. 両岸に安全な着岸場所がある渡河ラインを選ぶ。
4. 明確な洪水時の規則を定める。標示した水位を超えたら渡らない。

### 2. 船の建造または選定

1. 想定する積載量に安全余裕を加えて船体の大きさを決める。
2. 密閉式の浮力タンクまたは発泡材を追加し、浸水しても船が浮くようにする。
3. ケーブルまたは滑車用の強固な取り付け点を設ける。
4. 手すり、滑り止め付きデッキ、乗降ランプを備える。

### 3. ケーブルまたは推進装置の設置

1. 流れが船を保持する助けとなるよう、ケーブルを渡河地点の上流側に固定する。
2. 想定荷重を十分に上回る定格の滑車を使用し、シャックルは毎日点検する。
3. 緊急時に切り離せるよう、ケーブル取り付け部に鋭利なナイフを常備する。
4. ケーブルに目印を付け、着岸場所では頭の高さより低く保つ。

### 4. 安全な運航

1. 出発前に乗客と積荷を数え、標示された上限を決して超えない。
2. 重量を均等に配分し、乗客を着席させる。
3. 子どもと泳げない人には浮具の着用を義務づける。
4. 洪水時、夜間、強風時、視界不良時は運航を中止する。

## 安全上の注意

- **赤い危険：** 過積載や積荷の移動は船を転覆させるおそれがあります。溺水は急速に、そして静かに起こります。
- ケーブルや滑車が破断すると、致命的な力で跳ね返ることがあります。近づかず、毎日作業前に金具を点検してください。
- 冷たい水は急速に行動不能を引き起こします。浮具を着用し、乾いた着替えは密閉袋に入れて保管してください。
- 乗客を船やケーブルに結び付けてはなりません。
