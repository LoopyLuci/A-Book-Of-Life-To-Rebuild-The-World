# 手押し車と二輪荷車
> **Domain:** transport | **Difficulty:** apprentice | **Safety:** yellow

*本資料は参考情報にすぎません。実行に移す前に、一次資料および有資格の専門家に照らして必ず確認してください。本項目を唯一の情報源として用いてはなりません。*

## 概要

二輪荷車は、人間の運搬能力を数倍に高める。平坦で締まった地面では1人で100-300 kgを動かせる。悪路では、2人で50-100 kgを安全に動かせる。重要な要点は、頑丈な車軸、軽く回る車輪、低い重心、そして坂道用のブレーキである。

## 前提条件

- 木工または金属加工の基礎知識
- ベアリング付きの車輪、またはそれを製作・保守できる技能

## 材料と工具

- 硬木または鋼製の車軸
- ベアリングと空気入りタイヤを備えた車輪2個
- 木製の荷台と側面の柵
- ボルト、ワッシャー、ロックナット
- ブレーキまたはドラッグシュー（引きずり式制動具）
- ハンドルまたはハーネス（引き具）
- グリースと防水カバー

## 手順

### 1. 積載荷重に合わせた設計

1. 荷が車軸の後ろではなく車軸の真上にくるよう、荷台の長さを決める。
2. 荷台は低くする。荷が高いと、横傾斜で転倒しやすい。
3. 悪路では広い輪距を、小道や戸口では狭い輪距を用いる。
4. くぼみや制動に耐えられるよう、想定荷重の少なくとも2倍の強度で製作する。

### 2. シャーシの製作

1. 軸受ブロックまたは鋼製ブラケットで、荷台の下に車軸を取り付ける。
2. 車輪がフレームに擦れずに自由に回るように取り付ける。
3. ねじれに耐えるよう、荷台を斜めに補強する。
4. 引くための取り外し可能なハンドル、またはパッド入りのハーネスを取り付ける。

### 3. 操作性と制動の追加

1. 下り坂での荷に備え、ドラッグシュー、バンドブレーキ、またはロープブレーキを取り付ける。
2. 悪路で跳ねて外れることのないヒッチピンを使用する。
3. 手や肩が触れる面はすべて丸め、パッドを施す。
4. ばら積みの荷には、側面の柵または固縛点を設ける。

### 4. 積載と試験

1. まず空の状態で平坦地にて試験し、次に半分の荷重で試験する。
2. 重い物は車軸の真上、かつ荷台の低い位置に積む。
3. 荷は2本の独立した縛りで固定する。
4. 毎回の運行前に、タイヤの空気圧、車軸のナット、ブレーキを点検する。

## 安全上の注意

- **黄色の危険：** 荷を積んだ荷車は、坂道で暴走することがある。必ずブレーキを使用し、荷のバランスを保つこと。
- 座席と防護がない荷車には、人を乗せてはならない。
- 道路では反射マーカーまたはランプを使用する。荷車は低く、視認しにくい。
- 軟弱地盤での過積載は避ける。負傷の原因となり、道を傷める。
