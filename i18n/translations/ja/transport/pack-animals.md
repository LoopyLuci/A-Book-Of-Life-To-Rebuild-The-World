# 荷役動物と荷物輸送
> **Domain:** transport | **Difficulty:** apprentice | **Safety:** yellow

*本資料は参考情報にすぎません。実行に移す前に、一次資料および有資格の専門家に照らして必ず確認してください。本項目を唯一の情報源として用いてはなりません。*

## 概要

荷役動物（駄獣）は、車輪では通れない場所、すなわち急な山道、狭い小径、渡渉地点などで物資を運びます。健康な動物は、種類によりますが体重のおよそ20-30%、すなわち60-150 kgを積み、1日に10-30 kmを運びます。適切な鞍、釣り合いのとれた積荷、定期的な休息によって、輸送シーズンを早期に終わらせる鞍傷や疲労困憊を防げます。

## 前提条件

- 選んだ動物種の取り扱い経験
- 経路上での飼料、水、獣医の確保

## 材料と工具

- 動物に合わせた荷鞍（パックサドル）
- 鞍下パッドおよびブランケット
- パニア（振り分け荷袋）またはカーゴネット
- ロープおよびストラップ
- 足かせ（ホブル）および繋ぎ綱（ピケットライン）
- 動物用救急キット
- 飼料容器および水容器

## 手順

### 1. 動物の選定と調教・体づくり

1. おとなしく健全な動物を選びます。蹄、歯、背に傷がないか確認します。
2. 数週間かけて積荷を徐々に増やしながら慣らします。
3. その動物の平常時の行動と食欲を把握します。
4. 毎日の水場と放牧地を計画します。現地で見つかる飼料に頼ってはいけません。

### 2. 鞍の装着

1. 背に清潔なパッドを、しわや汚れのない状態で置きます。
2. 積荷が肩甲骨の後ろ、かつ腰（寛部）の前にくるように鞍を据えます。
3. 腹帯(girth)を徐々に締め、擦れがないか確認します。
4. 毎日背を点検します。熱を持った箇所は、開放性の傷になる前に処置します。

### 3. 積載とバランス

1. 積荷は体重の20-30%未満に抑えます。急斜面や軟弱な地面ではさらに減らします。
2. 重量は左右均等に振り分けます。重い物は低く、背骨に近い位置に載せます。
3. 胸帯(breast strap)と尻帯(breeching)で固定し、積荷がずれないようにします。
4. 鋭利な角は覆い、積荷が音を立てないようにします。はためく積荷は動物を驚かせます。

### 4. 移動と休息

1. 早朝に出発し、ゆっくり進み、暑い時期は正午に休憩します。
2. 休憩時は腹帯を緩めますが、体が熱いうちは鞍を外してはいけません。
3. こまめに水を与え、あらかじめ決めた間隔で飼料を与えます。
4. 停止のたびに、足、背、積荷を点検します。

## 安全上の注意

- **黄色の危険：** 動物は蹴り、噛み、押しつぶします。落ち着いて作業し、動物の真後ろには決して立たないでください。
- 積荷がずれると、急斜面では転落の原因になります。直ちに停止して積み直してください。
- 熱ストレスと疲労困憊は命取りになります。暑いときは積荷を減らし、日陰を用意してください。
- 動物の傷は速やかに処置してください。背の傷が感染すると、そのシーズンの輸送が不能になることがあります。
