# 貨物の固縛
> **Domain:** transport | **Difficulty:** novice | **Safety:** yellow

*本資料は参考情報にすぎません。実行に移す前に、一次資料および有資格の専門家に照らして必ず確認してください。本項目を唯一の情報源として用いてはなりません。*

## 概要

荷崩れを起こすと、荷車が転覆したり、動物が負傷したり、御者が投げ出されたりするおそれがあります。固縛は一つのシステムです。重量を分散し、重心を下げ、強度のある固定点に取り付け、数キロメートル走行したら張力を再点検します。ストラップを増やしても、積み方の悪さは補えません。

## 前提条件

- 基本的な結び方とロープの取り扱い
- 荷車、車両、または動物用の馬具に関する知識

## 材料と工具

- 定格荷重の表示があるストラップ、チェーン、またはロープ
- ソフトシャックルまたはエッジプロテクター
- 車輪止めと滑り止めマット
- 防水シートと固縛用の固定点
- 手袋と保護眼鏡
- 点検記録簿とナイフ

## 手順

### 1. 積載計画を立てる

1. 車両、荷車、または動物の積載限度と車軸の許容荷重を確認する。
2. 最も重い品物は低い位置に、車軸の後ろではなく車軸の真上に置く。
3. 左右のバランスを取り、荷の幅は実用上できるだけ狭くする。
4. 鋭利な角を保護し、相性の悪い物品は分けて積む。

### 2. 荷を固定する

1. 重い荷には、少なくとも二つの独立した拘束手段を用いる。
2. ストラップは、定格のあるフレームの固定点に掛ける。車体パネルや燃料配管には掛けない。
3. 均等に締め付け、ストラップが鋭い角をまたぐ箇所にはエッジプロテクターを使う。
4. 固くなって解けなくならない結び方を用い、余った端は結び留める。

### 3. 点検して走行する

1. 最初の数キロメートル走行したら停止してストラップを締め直す。荷は沈み込んで落ち着く。
2. 停止のたびに、また悪路を走った後や雨の後にも再点検する。
3. 走行を続ける前に、傾き、燃料のにおい、操舵の異常がないか確認する。
4. 荷下ろしは補助者をつけて行い、車輪に車輪止めをかけるか、動物の足を繋いで動かないようにする。

### 4. 点検と保管

1. 切れ、紫外線による劣化、繊維の断裂があるストラップは廃棄する。
2. ロープは乾かしてから巻き、直射日光の当たらない場所に保管する。
3. 損傷を記録し、次の運行の前に金具を交換する。
4. 緊急時にすぐ解放できるよう、ナイフを手の届く場所に置いておく。

## 安全上の注意

- **黄色の危険：** 荷崩れは手足を押しつぶし、車両を転覆させるおそれがあります。締め付けと荷下ろしの間は、人を近づけないでください。
- 損傷したストラップ、錆びたチェーン、滑るおそれのある結びは決して使わないでください。
- 最も弱い部品の使用荷重限度(WLL)を超えないでください。
- 燃料、化学薬品、動物は、それぞれ別に、換気を確保して固定してください。
