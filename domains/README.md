# Domains

The knowledge base is organized into 16 domains. Each domain is a self-contained
directory with a `README.md` index and one Markdown file per entry.

> Every entry in this book is reference material. Verify it against primary
> sources and qualified professionals before acting on it, and never use a
> single entry as a sole source of information. See
> [docs/DISCLAIMER.md](../docs/DISCLAIMER.md).

## Cross-Domain Threads

- **Prerequisites** link entries across domains (e.g.,
  `materials/charcoal-production` → `survival/making-fire`).
- **Shared materials** live in `materials/` and are referenced by all other domains.
- **Safety levels** escalate when combined (e.g., fire + chemistry = red).
