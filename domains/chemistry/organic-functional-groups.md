# Organic Functional Groups

> **Domain:** chemistry | **Difficulty:** apprentice | **Safety:** yellow

*Reference material only. Verify this information against primary sources
and qualified professionals before acting on it. This entry is not a sole
source of information.*

## Overview

Almost every useful organic molecule is a carbon skeleton with one or more
functional groups attached. Once you can name the groups, you can predict
reactivity, choose a synthesis route, and read a label on a drum of solvent.
The key principle is that the functional group, not the size of the carbon
chain, decides how the molecule reacts.

## Prerequisites

- None

## Materials & Tools

- Molecular model kits or printed structure cards
- A wall chart of functional groups and their reactions
- Melting point capillary tubes and a heating block
- Test tubes, a water bath, and a 10 mL graduated cylinder
- Class-test reagents: bromine water, neutral ferric chloride, litmus
  paper, and a bicarbonate solution

## Procedure

### Stage 1: Read a Skeletal Structure

1. Count every vertex and line end as a carbon.
2. Read each line and each ring as a carbon-carbon bond.
3. Note every heteroatom, since they are always written out.
4. Check that each carbon carries four bonds in total.
5. Circle the functional group before naming the compound.

### Stage 2: Recognise the Main Groups

1. Alkanes are saturated and give no class test.
2. Alkenes and alkynes are unsaturated and decolourise bromine water.
3. Alcohols give hydrogen bubbles with sodium and react with acids.
4. Aldehydes and ketones are carbonyl compounds that differ on oxidation.
5. Carboxylic acids and phenols are acidic; carboxylates are their salts.
6. Esters, amines, ethers, and halides each have their own characteristic
   tests.

### Stage 3: Run the Class Tests

1. Shake the sample with bromine water; the orange colour disappears if
   the sample is unsaturated.
2. Add neutral ferric chloride; phenols give a violet or blue colour.
3. Add sodium bicarbonate to an acid; it effervesces with carbon dioxide.
4. Test an aldehyde with Tollens' reagent; a silver mirror appears.
5. Test an alcohol with a small piece of sodium; hydrogen is released.

### Stage 4: Choose a Reaction

1. Match the desired transformation to a functional group change.
2. Choose the simplest reagent that performs that change.
3. Work out the by-products and write them down before starting.
4. Check that every functional group in the product is reachable.
5. Confirm the product by a class test or a melting point.

## Safety Notes

- Bromine water is corrosive and toxic; use it in a hood and never inhale
  the vapour.
- Tollens' reagent must be neutralised with dilute acid and discarded
  immediately, because silver-ammonia mixtures can leave explosive residues.
- Phenol is corrosive, toxic, and readily absorbed through skin.
- Alcohols and solvents are flammable; keep them away from flames.
- Never use smell as the test for an unknown; use a chemical test instead.
- Wear goggles and nitrile gloves for every class test.
